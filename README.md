# 🚀 Quick Start Guide

## Step 1: Install Dependencies
pip install -r requirements.txt

## Step 2: Run the Scraper
python run_scraper.py

## Step 3: Your Datasets Will Be Generated
- certificates_dataset.json (JSON format)
- certificates_dataset.csv (CSV format)

## Example Output Files:
📁 certificates_dataset.json
📁 certificates_dataset.csv  
📁 certificate_scraper.log

## Dataset Columns:
- learner_name
- certificate_title  
- organization_name
- date_issued
- certificate_id
- verification_url
- digital_signature
- public_comments
- platform
- extraction_date
